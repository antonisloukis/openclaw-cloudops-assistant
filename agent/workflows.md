# Agent Workflows

## Incident Investigation Workflow

1. Understand the reported issue.
2. Identify affected service.
3. Classify severity.
4. Suggest investigation steps.
5. Recommend remediation.
6. Generate prevention actions.


## Log Analysis Workflow

1. Parse log messages.
2. Identify errors and warnings.
3. Determine severity.
4. Find possible root causes.
5. Suggest next actions.


## Runbook Generation Workflow

1. Identify operational problem.
2. Create step-by-step procedure.
3. Include validation steps.
4. Include rollback considerations.
5. Add prevention recommendations.
